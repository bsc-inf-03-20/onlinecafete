Core flows

The routes that turn a cafe visit into a smooth digital experience.

Create account POST /api/auth/register POST /api/auth/login GET /api/auth/me
Browse menu GET /api/menu/items POST /api/menu/items GET /api/menu/categories
Place order POST /api/orders GET /api/orders PATCH /api/orders/:id/status
Track delivery POST /api/deliveries/assign GET /api/deliveries PATCH /api/deliveries/:id/status
